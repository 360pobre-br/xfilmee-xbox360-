
# XFILMEE

Aplicativo homebrew de catalogo de filmes
para Xbox 360 RGH.

## Recursos planejados

- Catalogo de filmes
- Capas personalizadas
- Sinopses
- Categorias
- Pesquisa
- Navegacao pelo controle
- Reproducao de videos locais autorizados

## Tecnologia

- C++
- Xbox 360 RGH
- XSDK
- CMake

## Desenvolvedor

VZNN
